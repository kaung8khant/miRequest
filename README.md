# Chrome Extension with Vite + PDF Generation

This is a Chrome Extension that handles form inputs and generates PDFs.

---

## 🚀 Getting Started

### 1. Install dependencies

```bash
yarn install
```

## Build the project

```bash
yarn build
```

## Watch for changes during development

```bash
npx vite build --watch
```

## 🧩 How to Install the Extension in Chrome

1. **Build the extension**

   Run the following command in your terminal:

   - `yarn build`

2. **Open the Chrome Extensions page**

   In Google Chrome, go to:

   - `chrome://extensions/`

3. **Enable Developer Mode**

   Toggle the **Developer mode** switch in the top-right corner of the page.

4. **Load the unpacked extension**

   - Click the **"Load unpacked"** button.
   - Select the `dist/` folder generated by the build command.

5. **You're done! 🎉**

   The extension should now be installed and visible in your Chrome extensions list.
